## Building systems for coding agents

I work on the infrastructure around AI coding agents: the parts that decide **what an agent may do, where it may do it, what context it receives, and how its result is proven**.

The objective is bounded autonomy. Deterministic work should be automated aggressively; authority, architecture, and verification should remain explicit.

</td>
<td width="42%" valign="top">
